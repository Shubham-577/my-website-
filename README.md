## 🚀 How to Run Locally

### Option 1: Just Double-Click!
You can **double-click `index.html`** directly in Windows File Explorer. It will open instantly in Google Chrome, Microsoft Edge, or Firefox. No command line, no terminal, and no installation needed!

### Option 2: Run with any local server (Optional)
If you have Python installed:
```powershell
python -m http.server 3000
```
Or with Node / npx:
```powershell
npx serve .
```

## 🐙 How to Upload to GitHub

Because all files are in this single folder with zero subdirectories, uploading to GitHub is super simple:

### Method A: Drag & Drop via Web Browser (Easiest)
1. Go to [github.com/new](https://github.com/new) and create a repository (e.g. `shubham-portfolio`).
2. Click **"uploading an existing file"**.
3. Select and drag all files from this folder (`index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md`) into your browser.
4. Click **"Commit changes"**. Done!

### Method B: Via Terminal / PowerShell
```powershell
git init
git add .
git commit -m "Shubham Sharma Cinematic Portfolio Website"
git branch -M main
git remote add origin https://github.com/shubhamsharma572007/portfolio.git
git push -u origin main
```

## ⚡ How to Deploy to Vercel (Free in 30 Seconds)

1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New..."** ➔ **"Project"**.
3. Import your GitHub repository.
4. Because this is a pure HTML/CSS/JS website, Vercel will instantly detect it as **Other / Static** with zero build configuration needed.
5. Click **"Deploy"**. Your site is now live at `https://your-portfolio.vercel.app`!
